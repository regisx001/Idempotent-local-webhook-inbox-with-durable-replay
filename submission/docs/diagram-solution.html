Two-Tier Decision Pipeline & Crash-Safe Durability

Architectural design decoupling delivery identity verification from entity finding monotonicity, backed by POSIX same-directory atomic state synchronization.

INVARIANT 1

Delivery Identity Separation

  • Idempotency Gate: Existing IDs compare canonical payload. Match → duplicate; mismatch → delivery conflict.
  • Zero Mutation: Repetitive or conflicting deliveries short-circuit immediately without touching finding entities.

INVARIANT 2

Key Reservation & Monotonicity

  • Immediate Key Reservation: Valid deliveries reserve IDs even when version-conflicted, ensuring subsequent redeliveries deduplicate.
  • Strict Progression: Finding versions strictly increase; stale versions are ignored and redundant statuses are logged.

INVARIANT 3 (ADR-04)

Crash-Safe State Swapping

  • Same-Directory Temporary File: Writes to sibling .{name}.tmp before atomic replace() inode swap.
  • Forensic Safety: Corrupt state files fail fast with exit 2, leaving existing on-disk bytes completely untouched.
